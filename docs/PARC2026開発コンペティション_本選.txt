概要
個人戦によるコンペティション形式

成功/衝突判定をゲートとして，重みと正規化した指標の積を計算する


time, jerk, SPARC, trajectory, rotationはそれぞれ正規化後の値を指す（正規化式は非公開）
各指標やタスクに対する依存性を低減するための，0〜1形式（連続値）への正規化
collision penalty は [0, 1] のバイナリ判定
各重みは 1 = w_1 + w_2 + w_3 + w_4 + w_5 とする（重みは非公開）
特定の指標に偏らせないための重み付け
リーダーボードと本選1/2/3の最終評価では総Trial数Nは異なります
Track毎に出るTotal Scoreの値を合計したものが各本選スコアとなります
仮に各本選最終評価フォームに提出されなかったTrackがあった場合，0点として計算されます

GPU・ライブラリ環境について
運営の採点環境と同一構成（CUDA 13.0、PyTorch 2.11.0+cu130 等)の Docker イメージをビルド済みで配布 GPU 環境に配置
提出前の動作確認（提出 zip のエンドツーエンド検証）も この Docker 内で実行することを推奨。
Omnicampus の採点環境の構成（CUDA / PyTorch / ライブラリの固定バージョン、プリインストール一覧）と、手元の Docker で同じ環境を再現する手順は、READMEの「採点環境」を参照。
ストレージについて
$HOME (/home/<account name>): 容量40GiB。
永続化ストレージ。10分ごと、およびインスタンス終了時に保存される。
インスタンス起動時に最後に保存された状態が復元される。
~/data: 容量100GiB。
永続化ストレージだが、永続化は手動で実施する必要がある。
保存手順: parc-home-sync data-push
復元手順: parc-home-sync data-pull
~/dataset: 配布データセット及びベースラインモデルが含まれる。読み出し専用。
/: 容量約1.7TB。インスタンス終了時に消える一時領域。
Dockerの使用について
Dockerは使用可能。
イメージの保存先は一時領域のため、毎回イメージをpullする必要があるので注意。

Notebookの起動・終了について
Notebookは、ブラウザタブを閉じたとしても、セルが実行されていて出力が流れていれば、一定時間の間は停止されません
「一定時間」＝デフォルトで12時間
ただし、「延長」ボタンを押すと、「押した時点から12時間後」になります
時間を無駄に消費したくない場合、カーネルを自分でシャットダウンするのを忘れないように！
